This Shiny app lets users select a U.S. state and view county-level Dominican population estimates from the 2020 American Community Survey. The app uses `tidycensus` to retrieve Census data and presents the results as state-specific maps.

View the live app: <a href="https://m-bueno-v.shinyapps.io/where-dominicans-app/">Dominican Population by State</a>.

View the source code: <a href="https://github.com/mbuenov/where-dominicans-at-app">where-dominicans-at-app</a>.
